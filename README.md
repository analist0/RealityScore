# RealityScore

מערכת אמון ודירוג מבוססת מיקום: מה הובטח, מה קיבלת, ואיך העסק טיפל בבעיה.

## MVP

- חיפוש לפי יישוב, עיר או עסק
- כרטיסי RealityScore
- תהליך ביקורת מודרך בעברית
- העלאת תמונות וקבלות ל-R2
- שמירת ביקורות ב-D1
- בסיס ל-Proof of Visit, איחוד כפילויות ומנוע גילוי עסקים
- פיילוט ראשון: מושב כלנית

## Stack

React 19, Next.js/Vinext, TypeScript, Cloudflare Workers, D1, R2, Drizzle ORM.

## Development

```bash
npm ci
npm run dev
npm run build
npm run db:generate
```
